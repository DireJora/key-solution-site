# n8n: нормативный поиск

В каталоге `workflows/` находятся два выключенных workflow:

- `normative-search.json` — поиск по allowlist официальных доменов ЕЭК, ФСБ, ФТС, Росаккредитации и другим государственным источникам;
- `normative-extract.json` — извлечение текста только из заранее выбранных официальных URL.

## Проверенное состояние

- поиск через Firecrawl вернул пять официальных источников;
- извлечены страница ФСБ и PDF ЕЭК;
- источник ФТС вернул ошибку внутреннего прокси Firecrawl, которая сохраняется вместе с URL;
- результат явно помечается как материал для проверки человеком, а не готовое юридическое заключение;
- workflow не активированы, не имеют расписания и не меняют amoCRM.

## Импорт

Workflow ссылаются на n8n credential типа `HTTP Header Auth`. Экспорт не содержит значение API-ключа. После импорта credential нужно создать или выбрать внутри n8n; ключ нельзя добавлять в JSON, `.env` репозитория или GitHub Secrets без отдельной необходимости.

До подключения Telegram, amoCRM или публичного webhook нужно добавить проверку входных данных, allowlist доменов и подтверждение Кириллом перед любым юридическим выводом или внешним сообщением.
